# Penjelasan

nah diproject saya kali ini ingin membuat sebuah website rental ps untuk salah satu umkm di daerah saya, nah di dalam web saya ini saya membuat beberapa section sesuai yang di pahami oleh ai saya namun belum tepat. akan saya jelaskan, perhatikan gambar landingpage saya di gambar 2. di nav section ada logo, navigation links, dan tombol, di sini saya belum tahu tombol nya untuk apa, tapi nanti kita kambangkan seiring jalannya project. di nav ini posisinya akan selalu di atas layar, seperti navigasi pada umumnya. nah di home atau hero, saya menampilkan logo rental, decoration, tombol contact (ini saya lupa ganti, saya ingin menggunakannya untuk tombol explore, jadi ketika di klik akan ke section selanjutnya) dan beberapa card dengan gambar game. list game section saya menampilkan title, description, dan beberapa card, card di sini adalah hard ware rental yang di sediakan, ada playstation, nintendo switch, dan logitech whell. nah di sini jika tombol card di klik akan menampilkan list game di dalamnya. misal playstation di klik, akan memunculkan semua list game yang ada di hardware playstation (ps 3, ps 4, ps 5), begitu pula di nintendo switch, dan yang lain. setiap hardware memiliki list game berbeda beda. pricing section, di sini ada title, option tab dan card atau container, nah di option tab adalah sebuah pilihan tab yang tiap tab akan memunculkan isi container yang berbeda beda, misal di tab 1 menampilkan price paket harian, tab 2 menampilkan price harga sewa, tab 3 menampilkan tab harga member, dll. event section, di sini ada title dengan design seperti police line, niatan saya ketika di scroll line eventnya seperti berjalan (saya membuat line ini manual di figma, dan saya menbuatnya dengan ukuran pas sesuai ccanvaas landigpage (width), nah agar bisa di scroll sesuai kemauan saya, apakah sebaiknya di buat manual melalui codigna atau saya berikan assets dengan ukuran dan layout yang di gunakan di figma (kurang fleksibel)). lalu ada card event, di dalamnya ada poster event, title, subtitle, description atau caption, timedate (tanggal event berjalan), button (ini untuk melihat event lebih detail, biasanya event di posting di instagram, jadi akan menuju ke sana) gallery section, di sini ada huruf decoration G A L L E R Y, dan ada lingkaran lingkaran, nah si lingkaran ini nantinya akan berupa gambar seperty gallery pada umumnya, di sini niatnya saya di buat interaktif, jadi decoration text dan lingkaeran imagenya seperti mengambang di luar angkasa dan bergerak random (masih di sekitaran section gallery), dan jika lingkaran di hover maka lingkaran agar sedikit membesar, dan jika di klik akan memunculkan gambar fullnya. location section, di sini background sudah menjadi biru, dan niatnya saya buat parallax, jadi dari gallery jika di scroll, maka akan ada parallax seperti bagian atau background biru bergerak ke atas menutupi gallery atau bagian background putih. di dalam location ada title, dan card maps, di card maps akan memunculkan maps dengan mark lokasi rental berada. misal ada 3 cabang, jadi di maps tersebut akan menmpilkan 3 titik untuk menandakan lokasi rental. ini menggunakan maps real, danuser bisa menggeser maps layaknya aplikasi maps. testimoni section, di sini akan menampilkan beberapa kommentar yang berupa card, di dalam card berisi profile, commentar, dan syaa lupa menambahkan bintang, jadi di bawah card akan menampilkan bintang .../5 bintang, seperti testimoni pada umumnya. FAQ Section, di sini akan menampilkan beberapa bar faq yang jika di klik akan muncul dropdown jawabn dari pertanyaan di barnya. contact us section, di sini ada title, description, dan button. button ini jika di klik akan menghubungi admin mellui whatsapp. footer, di sini ada logo, description, nav links, social media (yang lingkaran), copyright. tambahan: saya ingin web ini bisa di otak atik melalui dashboard admin, jadi di dashboard admin akan menampilkan statistik, seperti seberapa kali web di kunjungi, dll (intinya mendapatkan informasi atau awearnes rental tersebut), lalu admin dashboard dapat mengganti sesukanya sperti logo, image, title, description, color, faq, isi kontent, atur price, event, dll. (btw color yang sya gunakan yaitu FAFAFA, 0000FF, 1D242B.). maka dari itu memerlukan database yang terstruktur, rapi, profesional, base practice, dll. saya ingin struktur folder, penamaan file tersusun rapi seperti provesional dan base practice, dan saya tidak ingin membuat 1 file yang isinya banyak baris, jadi saya ingin itu di pecah menjadi beberapa bagian sehingga 1 file tidak berisi ribuan baris code agar mudah di maintenance, lalu buat component yang di perlukan di dalam folder component, seperti card, button, dll (yang sering di gunakan, element di web, dll) nah dari penjelasan web saya ini tolong buatkan plan gambaran project saya agar agent mengetahui dan memahami tujuan, struktur, systemnya terlebih dahulu sebelum bekerja ke step kedepannya.
